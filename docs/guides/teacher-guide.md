# Teacher Guide

## Login & Navigation
- Click your name on login screen (or type username)
- Switch user: top right button (< 10 seconds)
- Auto-lock after 15 min idle - drafts saved

## Attendance

### Mark Attendance
1. Attendance → Select your class
2. Default: All Present (one-click)
3. Change individual: Present/Absent/Late/Excused
4. Add remarks per student
5. Save → auto-submits

### Features
- Keyboard: Tab/Enter/Arrow navigation
- 60 students in < 2 minutes
- Only your assigned classes visible
- Real-time sync in LAN mode

### Attendance Reports
- View your classes only
- Chronic absence alerts
- Attendance auto-included on report cards

## Grades

### Enter Grades
1. Grades & Reports → Select class & subject
2. Spreadsheet-like grid:
   - Tab/Enter/Arrow navigation
   - Paste from Excel
   - Instant totals
3. Auto-save drafts (recovered on crash/restart)
4. Blank ≠ Zero (shows "not entered")

### Grade Components
- Configured by Principal: Classwork, Homework, Midterm, Exam
- Weights must total 100
- Max score per component

### Grade Workflow
```
Draft (you) → Submit → Homeroom Review → Principal Approve → Published
```
- **Submit**: Locks your editing, notifies homeroom
- **Cannot edit after submit** (unless returned)
- **Published = locked** (no changes without Principal unlock + reason)

### Missing Grades
- Show as "not entered" (never zero)
- Publishing warns about incomplete sheets
- All totals match grade sheet exactly

## Report Cards (Homeroom Teacher)
If you're class teacher:
1. Conduct: behavior, attitude
2. Attendance summary (auto-filled)
3. Teacher remark
4. Principal adds remark + signature

## LAN Mode (Phone/Tablet)
1. Principal enables LAN mode
2. Scan QR code on phone
3. Log in with your credentials
4. Mark attendance/enter grades on phone
5. Syncs to PC within 2 seconds
6. Works offline after initial load
7. Router off → shows "Connection lost" message

## Switch User / Lock Screen
- **Switch User**: Top bar button, returns to login in < 10s
- **Your drafts**: Auto-saved, restored on re-login
- **Lock Screen**: 15 min idle (configurable)
- **After lock**: Screen cleared, PIN to unlock, drafts restored

## Keyboard Shortcuts
| Action | Keys |
|--------|------|
| Next cell | Tab / Enter |
| Previous cell | Shift+Tab |
| Move up/down | Arrow keys |
| Save draft | Auto |
| Submit grades | Ctrl+Enter (in grade sheet) |

## Troubleshooting
| Issue | Fix |
|-------|-----|
| Can't see class | Check teaching assignments in Settings |
| Grades not saving | Check draft status, submit when done |
| Phone won't connect | Same Wi-Fi, scan QR, check Principal enabled LAN |
| Lost draft | Restart app - auto-recovered from IndexedDB |
| Can't edit after submit | Ask Principal to return for revision |

## Important Rules
- **Never share password** - each staff has own account
- **Log out** when leaving computer
- **Lock screen** (Win+L) for short breaks
- **Switch user** for longer breaks - preserves your work
- **Report issues** immediately - audit log tracks everything
