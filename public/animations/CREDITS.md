## Usage in Belko Edu-Platform

These animations are bundled inside the application (`dist/assets/animations/`) and work fully offline. No CDN or external network requests are made for animations.

Animations are recolored at runtime using the school's chosen primary color (set during onboarding in Settings → Branding), with a neutral fallback (`#6b7b7a`).

A "Reduce animations" setting (Settings → Appearance, Principal only) respects the OS `prefers-reduced-motion` preference and allows manual override. When enabled, animations show only their first static frame.
